确定docs文件夹内容不上传github，以后只上传log文件夹个人日志内容，修改.gitignore内容：
docs/



从索引中移除：

git rm -r --cached docs 



\--cached

这两个字不能漏。



\- 带 `--cached`：只从 Git 索引删，\*\*你本地文件还在\*\*

\- 不带：会连本地文件一起删掉



提交这个变更：

git add .gitignore

git commit -m "chore: docs 目录不再纳入版本库"

git push



验证：

git status

Changes to be committed:
	deleted:    "docs/第1周-..."
	modified:   .gitignore



git add -A  加入所有变化。
git status
