今天的数据流（先看懂这四步，代码就都是它）

用户问题

&#x20;  │

&#x20;  ├─ Agent 判断「这个要查文档」→ 调用 search\_docs(query) 工具

&#x20;  │        │

&#x20;  │        ├─ embed\_texts(\[query])                       ← DashScope，一条查询一次

&#x20;  │        ├─ hybrid\_search(...)                          ← Milvus 双路召回 + RRF，按 parent\_id 去重

&#x20;  │        ├─ batch\_get\_with\_filename(parent\_ids)         ← 回 PG 拿父块全文 + 文件名

&#x20;  │        └─ 给每个父块编号 ref-{parent\_id\[:8]}，返回 JSON 字符串

&#x20;  │

&#x20;  ├─ 模型读工具返回的原文 → 生成回答，句末标 \[ref-xxx]

&#x20;  │

&#x20;  └─ 我们在 on\_tool\_end 把 sources 收进口袋

&#x20;           │

&#x20;           ├─ 推 event: additional\_info  {"sources": \[...]}

&#x20;           ├─ 落库 messages.sources（JSONB）

&#x20;           └─ 推 event: done  {"ok": true, "run\_id", "message\_id", "sources": N}
